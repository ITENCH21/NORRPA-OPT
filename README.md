# NORPPA для магазинов: лендинг для оптовых партнёров

Одностраничный сайт в одном файле `index.html`, без сборки и зависимостей. Шрифты (Unbounded, Golos Text) берутся из Google Fonts, фото товаров — по прямым ссылкам с shop.norppa.ru.

## Как выложить на GitHub Pages
1. Создайте на github.com новый репозиторий, например `norppa-wholesale`.
2. Загрузите в него файлы из этой папки: **Add file → Upload files → перетащить `index.html` и `README.md` → Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, затем **Branch: main** и папку **/(root)**. Нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/norppa-wholesale/`.

Через терминал то же самое делается так:
```bash
cd site
git init && git add . && git commit -m "NORPPA wholesale landing"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/norppa-wholesale.git
git push -u origin main
```

## Что поменять перед показом
- **Почта для заявок.** Форма открывает письмо на `office@norppa.ru`. Чтобы заявки шли вам, замените адрес в `index.html` — он встречается в форме, в блоке контактов и в скрипте (`mailto:office@norppa.ru`).
- **Телефон** — в блоке «Запросите оптовый прайс».
- **Модели в «коллекции-карте»** — массив `places` в конце файла: название, что это за место, тип изделия и ссылка на фото.
- **Индексация.** Сейчас стоит `<meta name="robots" content="noindex">`: это концепт для презентации, и поисковики его не индексируют. Если страница станет официальной, удалите эту строку.

## Важно
- Фото подгружаются с shop.norppa.ru. Если в магазине поменяют картинки, ссылки нужно обновить. Для постоянной версии лучше положить фото рядом с `index.html`.
- Цифры на странице — из открытых данных на ноябрь 2026 года: 40 000+ продаж на WB, рейтинги 4,7 и 4,9, количество моделей. Перед официальным запуском сверьте их с отделом маркетплейсов.
